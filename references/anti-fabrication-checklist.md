# Anti-fabrication checklist

For each Japanese clause, ask: **which source payload is this?** If there is no answer, it's a fabrication.

## Additions that slip in during transcreation
- [ ] **Urgency:** 今だけ, 期間限定, 急いで, お早めに, 今すぐ (when the source has no time pressure). "today" in a soft CTA ≠ 今だけ.
- [ ] **Scarcity:** 残りわずか, 数量限定, 先着
- [ ] **Free / no-risk:** 無料, 簡単に解約, リスクなし (unless the source says so)
- [ ] **Escalated claims:** 必ず, 絶対, 最高, No.1, 日本初, 業界最速 from milder English
- [ ] **Invented emotion:** 感動, 嬉しい, 大好き when the source states a fact
- [ ] **Added social proof:** 大人気, 話題の, 多くの方に選ばれている
- [ ] **Added seasonal or cultural hooks** with no source counterpart
- [ ] **Added hashtags, emoji, or @mentions**
- [ ] **Explanatory padding:** a clause explaining something the English left implicit, unless it's needed for comprehension; if so, note it

## Omissions that slip in
- [ ] Hedges dropped: "up to" (最大), "can" (〜できる), "may" (〜場合がある), "about" (約)
- [ ] Qualifiers and disclosures dropped for length: *conditions apply, #ad, #PR, 提供, terms in bio*
- [ ] Second clauses of compound benefits ("faster **and** quieter")
- [ ] Sign-offs, thread markers (1/5), emoji-only lines
- [ ] Part of the CTA ("Shop now **and save 20%**")

## Changed facts
- [ ] Numbers, units, currency, dates, times (and time zones: "9am PT" must not silently become JST)
- [ ] URLs (including UTM parameters), promo codes, @handles, hashtag spelling and case
- [ ] Product names, model numbers, feature names
